# إدارة مشاريع شركة البهجة

تطبيق تشغيل فعلي: المشاريع والمهام والمستخدمون على Google Drive، والرابط نفسه لكل الحاسبات.

**الرابط:** https://alipicasso.github.io/bahja-pm/

## الاستخدام

1. اربط جوجل درايف بحساب الشركة `picassomega86@gmail.com`.
2. ادخل بحساب النظام (مدير مشاريع أو مستخدم آخر). أول دخول يطلب تغيير كلمة المرور الافتراضية.
3. مدير المشاريع يضيف المستخدمين من قائمة **المستخدمون**.
4. اختياري: من Chrome أو Edge → تثبيت التطبيق على المكتب. التحديثات تصل من نفس الرابط بعد رفع الكود.

## التعديل لاحقاً

الملفات في هذا المجلد. بعد التعديل ارفع إلى GitHub فيتحدّث الرابط لكل الأجهزة. لا حاجة لإعادة تثبيت.
